## 🌟 Key Features

1. **🛡️ RBI Account Aggregator (AA) Granular Consent**
   - Connects seamlessly with leading Indian banks (HDFC, SBI, ICICI, Axis, Kotak, PNB, Canara, Indian Bank, and more).
   - Granular, revocable user consent toggles with client-side cryptographic isolation.

2. **📊 Multi-Goal Priority Engine & Predictive MADM Simulation**
   - Multi-Attribute Decision Making (MADM) modeling to simulate how unexpected expenses impact multiple financial targets (e.g., Emergency Fund, Higher Education, Home Down Payment).
   - Dynamic target reallocation and trade-off calculation.

3. **🚨 Isolation Forest Anomaly Guard**
   - Machine learning anomaly detection identifying unusual spending spikes and subscription creep in real time.
   - Interactive simulation mode to test spike injection and immediate guardrail responses.

4. **💬 Autonomous WhatsApp Telemetry Nudges**
   - Dispatches instant alerts via WhatsApp in both **English** and **Tamil (தமிழ்)**.
   - One-click interactive safety interventions and category overrides.

5. **📱 Dual-View Synchronized Experience**
   - Full desktop financial telemetry cockpit alongside an interactive mobile app simulator.
   - 100% responsive across desktop, tablet, and mobile browsers.

## 🚀 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/anusuyap2697-ux/flowbank-ai-banking.git
   cd flowbank-ai-banking
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
